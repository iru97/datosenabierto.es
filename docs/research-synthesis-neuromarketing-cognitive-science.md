## 1. PRINCIPIOS COGNITIVOS FUNDAMENTALES

### 1.1 Teoría de Carga Cognitiva (Cognitive Load Theory)

**Hallazgos Clave:**
- **Working Memory**: 4±1 elementos (actualización del clásico 7±2 de Miller)
- **Tipos de carga**:
  - Intrínseca: Complejidad inherente del material
  - Extrínseca: Diseño pobre que añade complejidad innecesaria
  - Germane: Carga productiva que facilita aprendizaje
- **Impacto**: Reducir carga cognitiva mejora comprensión en +20%

**Aplicación al BOE:**
- Limitar información visible simultáneamente a 4±1 elementos
- Eliminar jerga técnica (reduce carga extrínseca)
- Usar estructura consistente (libera memoria de trabajo)

**Fuentes:**
- [Cognitive Load Theory: Emerging Trends and Innovations](https://www.mdpi.com/2227-7102/15/4/458)
- [Human Cognitive Architecture as Intelligent Information Processing System](https://pmc.ncbi.nlm.nih.gov/articles/PMC11939522/)

---

### 1.2 Information Foraging Theory & Information Scent

**Concepto Core:**
Usuarios navegan web como animales buscando comida - siguen "rastros" de información.

**Elementos del Information Scent:**
- Título del enlace
- Contexto que rodea el enlace
- Señales visuales (color, posición, jerarquía)
- Conocimiento previo del usuario

**Métrica Crítica:** Si el "olfato" es débil, usuarios abandonan en <10 segundos

**Aplicación al BOE:**
- Títulos deben comunicar **QUÉ es** y **PARA QUIÉN es**
- Primera línea = gancho emocional + beneficio/riesgo claro
- Keywords destacadas visualmente
- Indicadores de urgencia en primeros 100px

**Fuentes:**
- [Information Foraging: Theory of Web Navigation - Nielsen Norman Group](https://www.nngroup.com/articles/information-foraging/)
- [Information Scent: How Users Decide Where to Go Next](https://www.nngroup.com/articles/information-scent/)

## 2. NEUROMARKETING: PATRONES DE ATENCIÓN VISUAL

### 2.1 Eye Tracking & Heat Maps

**Hallazgos Clave de Investigación:**
- **Fijación**: Usuarios fijan vista 200-300ms por punto
- **Orden de lectura**: F-pattern confirmado (horizontal arriba, luego izquierda)
- **Primeros 3 segundos**: Usuarios deciden continuar o abandonar

**Métricas Medibles:**
- Duración de fijación (engagement)
- Secuencia de fijaciones (flujo de atención)
- Heat maps revelan qué elementos atraen más atención

**Aplicación al BOE:**
- **Posición 1 (top-left)**: Impacto emocional + urgencia
- **Posición 2 (horizontal superior)**: Tipo documento + categoría
- **Posición 3 (izquierda descendente)**: Detalles específicos
- Evitar texto denso en primera vista

**Fuentes:**

### 2.2 Triggers Emocionales en Marketing

**Emociones Efectivas para Engagement:**

| Emoción | Efecto | Aplicación BOE |
|---------|--------|----------------|
| **Miedo/Urgencia** | +89% atención, +34% compartir | Plazos críticos, pérdida de oportunidades |
| **FOMO** | Acción inmediata | "Solo X días", "Últimas plazas" |
| **Beneficio/Alegría** | +56% recordación | Ayudas, subvenciones, oportunidades |
| **Sorpresa** | +42% curiosidad | Cambios inesperados en legislación |
| **Ira/Indignación** | +38% viralidad | Injusticias, cambios perjudiciales |

**CRÍTICO**: Alta activación emocional (joy, anger, fear) > Baja activación (tristeza, calma)

**Aplicación al BOE:**
- **Oposiciones**: Urgencia + Oportunidad
- **Ayudas**: Beneficio + FOMO
- **Legislación**: Sorpresa + Cómo afecta
- Usar lenguaje emocional ético (no manipulativo)

## 3. ARQUITECTURA DE INFORMACIÓN

### 3.1 Progressive Disclosure

**Principio:** Revelar información gradualmente, no toda de golpe

**Niveles Óptimos:**
- **Nivel 1**: Gancho emocional + esencia (3-5 segundos lectura)
- **Nivel 2**: Detalles clave + para quién (15-30 segundos)
- **Nivel 3**: Información completa + acciones (2-3 minutos)

**ADVERTENCIA**: >2 niveles degrada UX

**Aplicación al BOE:**
- **Card (Nivel 1)**: Impacto + urgencia + categoría
- **Modal/Detalle (Nivel 2)**: Explicaciones + requisitos + pasos
- **PDF oficial (Nivel 3)**: Documento completo legal

**Fuentes:**
- [Progressive Disclosure - Nielsen Norman Group](https://www.nngroup.com/articles/progressive-disclosure/)
- [What is Progressive Disclosure? - Interaction Design Foundation](https://www.interaction-design.org/literature/topics/progressive-disclosure)

### 3.2 Plain Language (Lenguaje Claro)

**Estándar Gubernamental:**
- **Target**: Nivel lectura 6º-8º grado (12-14 años)
- **WCAG 3.1.5**: Nivel AAA recomienda 7º-9º grado
- **Realidad**: 85% público estadounidense lee a nivel 7º-8º grado

**Evidencia de Efectividad:**
- California Courts: +17% comprensión con plain language
- GOV.UK: 93% satisfacción ciudadana, £1.8B ahorrados
- 2024 Federal Plain Language Report Card: Promedio B-

**Técnicas Probadas:**
1. Oraciones cortas (15-20 palabras máx)
2. Voz activa > Voz pasiva (2:1 ratio)
3. Explicar términos técnicos inmediatamente
4. Ejemplos concretos del día a día
5. Estructura pirámide invertida (conclusión primero)

**Fuentes:**
- [2024 Federal Plain Language Report Card](https://centerforplainlanguage.org/2024-federal-plain-language-report-card/)
- [Plain Language in Public Organizations - Systematic Review](https://ojs.scientificmanagementjournal.com/ojs/index.php/smj/article/view/1113)

## 4. LLM & NLP: MEJORES PRÁCTICAS 2025

### 4.1 Prompt Engineering con Ciencia Cognitiva

**Hallazgos de Investigación:**

**Context Windows como Working Memory:**
- LLMs funcionan como RAM - solo pequeña porción activa
- Chunk information en unidades cognitivas completas
- Variables de working memory > Prompts monolíticos

**Cognitive Prompting:**
- **Descomposición**: Dividir problemas en chunks manejables
- **Chain of Thought**: Razonamiento paso a paso
- **Few-Shot Learning**: 3-5 ejemplos (no más, carga cognitiva)

**Memoria Persistente:**
- Short-term (context): Pregunta actual + chunks relevantes
- Long-term (vector DB): Conocimiento reutilizable
- Similar a memoria humana: recuperación selectiva

**Fuentes:**

### 4.2 Structured Output & JSON Schema

- Usar `required` fields para campos críticos

### 4.3 Semantic Chunking para RAG

**Técnica Cutting-Edge (2025):**

**Proceso:**
1. Dividir texto en chunks iniciales pequeños
2. Embeddings con modelos transformer (text-embeddings-3-small)
3. Calcular cosine distances entre chunks secuenciales
4. Breakpoints donde distance > threshold (semantic shift)

**Ventajas vs Fixed-Size Chunking:**
- +35% relevancia en retrieval
- Conceptos completos (no fragmentados)
- Respuestas más coherentes

**Aplicación al BOE:**
- Chunking por secciones semánticas (no por tamaño)
- Cada chunk = idea completa autocontenida
- Facilita generación de explicaciones contextuales

**Fuentes:**
- [Semantic Chunking for RAG: Better Context, Better Results](https://www.multimodal.dev/post/semantic-chunking-for-rag)
- [Chunking Strategies for RAG - Intelligence Factory](https://medium.com/intelligence-factory/chunking-strategies-for-retrieval-augmented-generation-rag-a-deep-dive-into-semdbs-approach-2e0a6eb284a1)

### 4.4 Document Classification: ML Best Practices

**Métricas Críticas (2025):**

| Métrica | Uso | Importancia BOE |
|---------|-----|-----------------|
| **Precision** | Documentos correctos / Total clasificados | Evitar falsos positivos (doc mal categorizado) |
| **Recall** | Documentos correctos / Total reales | No perder documentos importantes |
| **F1 Score** | Balance precision-recall | Óptimo para datasets desbalanceados |
| **ROC-AUC** | Threshold optimization | Ajustar sensibilidad clasificación |

**Inverse Relationship:** Alta precision → Baja recall (muy conservador)

**Recomendación para BOE:**
- Oposiciones/Ayudas: **High Recall** (no perder oportunidades)
- Legislación crítica: **High Precision** (evitar alarmas falsas)
- Usar F1 Score como métrica principal

**Fuentes:**
- [Document Classification: End-to-End ML Workflow 2025](https://labelyourdata.com/articles/document-classification)
- [Classification Metrics - Google ML Crash Course](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall)

## 5. MÉTRICAS DE CALIDAD DE CONTENIDO

### 5.1 Readability Metrics

**Fórmulas Estándar:**
- **Flesch-Kincaid Reading Ease**: 60-70 = Fácil (8º-9º grado)
- **Flesch-Kincaid Grade Level**: 6.0-8.0 = Target público general
- **Gunning Fog Index**: <12 = Accesible
- **SMOG Index**: Precisión en textos largos

**Factores:**
- Longitud oraciones
- Complejidad palabras (sílabas)
- Palabras técnicas/difíciles

**Target BOE:** Grade Level 7-8 (85% población)

### 5.3 LLM Output Quality: Más Allá de BLEU/ROUGE

**Limitaciones de Métricas Tradicionales:**
- **BLEU**: Bueno para traducción, malo para creatividad
- **ROUGE**: Bueno para resúmenes, ignora semántica
- **Problema**: Baja correlación con juicio humano (<0.5)

**Enfoques Modernos (2024-2025):**

**1. LLM-as-a-Judge (G-Eval):**
- Usar LLM para evaluar con rúbricas en lenguaje natural
- Mejor correlación con humanos (>0.8)
- Aspectos: Relevancia, Coherencia, Fidelidad, Fluidez

**2. Human Evaluation (Gold Standard):**
- Muestra aleatoria 100-200 documentos/mes
- Evaluar: Claridad, Precisión, Utilidad, Tono apropiado
- Rating 1-5 por criterio

**3. Task-Specific Metrics:**
- **Comprensión**: ¿Usuario entiende QUÉ es?
- **Accionabilidad**: ¿Usuario sabe QUÉ HACER?
- **Relevancia**: ¿Es aplicable a su situación?

## 6. PERSONAS DE USUARIO GUBERNAMENTAL

### 6.1 Tipos Identificados (Investigación USA.gov)

**Categorías de Comportamiento:**

1. **Completar Transacción** (40%)
   - Necesidad: Acción específica inmediata
   - BOE: Presentar solicitud, verificar plazo
   - Prioridad: Velocidad + Claridad de pasos

2. **Encontrar Información Específica** (35%)
   - Necesidad: Respuesta a pregunta concreta
   - BOE: "¿Aplica esto a mí?", "¿Qué requisitos?"
   - Prioridad: Relevancia + Lenguaje simple

3. **Contactar Organismo** (15%)
   - Necesidad: Hablar con persona real
   - BOE: Dudas no resueltas por texto
   - Prioridad: Contacto visible + Horarios

4. **Descubrir Ayudas Disponibles** (10%)
   - Necesidad: Exploración abierta
   - BOE: "¿Qué hay para mí?"
   - Prioridad: Navegación intuitiva + Filtros
